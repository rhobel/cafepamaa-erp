Principles

How to apply the system

Neutral first

Greys, 1px borders and soft shadows carry the layout. Colour only appears where it means something.

Yellow = focus

Use brand yellow for the single primary action, the active nav marker, selected rows and focus rings — nothing else.

Numbers are the hero

Large tabular figures, right-aligned money columns, delta chips for change over time.

Do / Don't

Black text on yellow
White or yellow text on yellow
Status as badge + label
Colour-only status
One yellow button per view
Yellow on every button
